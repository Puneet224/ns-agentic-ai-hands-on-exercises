# AI Foundations Lab

This repository contains a Python sandbox environment for AI foundations work.

## Setup

1. Activate the virtual environment:

```powershell
.\venv\Scripts\Activate
```

2. Install dependencies:

```powershell
pip install -r requirements.txt
```

## Notes

- The virtual environment is excluded from version control via `.gitignore`.
- Add your Python packages to `requirements.txt` as needed.
